🔑 Service Account Credentials

Firebase's legacy Server Key API was permanently shut down on June 20, 2024. This panel now uses the modern FCM HTTP v1 API, which requires a Service Account JSON key from your Firebase project.

  1. Open Firebase Console → Project Settings → Service Accounts
  2. Click "Generate new private key" → "Generate key"
  3. A .json file downloads to your computer
  4. Open the file in any text editor, copy all the content
  5. Paste it into the field below and click Save
⚠️ This JSON key gives admin access to your Firebase project. Only paste it on a trusted device. It is stored in your browser's localStorage and never leaves your device (all sending happens directly from your browser to Google's FCM servers).

ℹ️ How Sending Works

When you click Send, this page:
① Signs a JWT with your service account private key (using your browser's built-in Web Crypto API)
② Exchanges the JWT for a short-lived OAuth 2.0 access token from Google
③ Calls the FCM HTTP v1 API once per subscriber (50 at a time)
④ Shows you the delivery count when complete

The private key is only used in-browser. OAuth tokens expire after 1 hour and are cached in session storage.
