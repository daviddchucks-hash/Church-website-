App Control
🔧 First-Time Setup (Required Once)

App Control uses Firebase Realtime Database to broadcast status changes to every device in real-time (sub-second latency). Click the button below to verify the RTDB connection before using the mode buttons. Ensure /appSettings has ".read": true in your Firebase Security Rules.

Required Firebase Security Rules

App Control writes to /appSettings without authentication, so you must allow ".write": true on that path in your Firebase Rules. This is safe — /appSettings only stores the app mode (online/maintenance/etc.), not sensitive data. The admin panel is already password-gated.

1. Open Firebase Console → Realtime Database → Rules
2. Replace the rules with the JSON below
3. Click Publish — mode buttons will work immediately 
{
  "rules": {
    "appSettings": {
      ".read":  true,
      ".write": true
    },
    "fcm-tokens": {
      ".read":  false,
      ".write": true
    }
  }
}
